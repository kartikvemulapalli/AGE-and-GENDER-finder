# Age and Gender Detection System 👨👩🦳👶


A real-time age and gender detection system using OpenCV and pre-trained Caffe models. This application detects faces in images/videos/webcam feed and predicts both age group and gender for each detected face.

## Features ✨

- Real-time face detection
- Age group classification (8 categories)
- Gender classification (Male/Female)
- Supports images 
- CPU/GPU acceleration support
- Simple command-line interface
